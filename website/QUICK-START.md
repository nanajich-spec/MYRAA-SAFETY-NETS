# Myraa Safety Nets - Quick Start Guide

## 🚀 First Time Setup (Next 5 Minutes)

### Step 1: Update Your Contact Information

**Required Updates:**

1. Open `index.html` ✋
   - Find `+919876543210` and replace with your mobile number (4 occurrences)
   - Find `myraa@myraasafetynets.com` and replace with your email
   
2. Open `js/config.js` ✋
   - Update `phoneNumber` with your number
   - Update `whatsappNumber` without + sign (e.g., 919876543210)
   - Update `email`
   - Update `socialMedia` links

3. Open `js/script.js` ✋
   - Find WhatsApp link around line 33
   - Replace phone number

**Time Needed:** 2 minutes

---

### Step 2: Add Your Business Images

**Recommended Images:**

1. **Hero Section Image** (1920x1080px)
   - Save as: `images/hero-banner.jpg`
   - Content: Your best service photo or team

2. **Service Images** (600x400px each)
   - `images/balcony-net.jpg` - Installed balcony net
   - `images/pigeon-net.jpg` - Pigeon net installation
   - `images/child-net.jpg` - Child safety net
   
3. **Gallery/Testimonial Images**
   - Before/after installation photos
   - Team photos
   - Customer reviews

---

### Step 3: Test the Website

1. **Open in Browser:**
   ```
   File → Open → Select index.html
   Or use any web server
   ```

2. **Check These:**
   - ✓ All phone numbers visible
   - ✓ Contact form works
   - ✓ WhatsApp button works
   - ✓ Mobile view responsive
   
3. **Test Contact Form:**
   - Fill and submit
   - Should open WhatsApp with message

**Time Needed:** 3 minutes

### If Using WordPress Host

1. Install WordPress from control panel
2. Use a theme similar to our design
3. Create pages matching our structure
4. Import our content
5. Keep the same color scheme

### Google Analytics Setup

Add this to `<head>` section of index.html:

```html
<script async src="https://www.googletagmanager.com/gtag/js?id=GA_MEASUREMENT_ID"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'GA_MEASUREMENT_ID');
</script>
```
